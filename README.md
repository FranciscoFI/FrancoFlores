# Franco Flores · Fotografía

Página principal minimalista con el mismo estilo blanco y tipografía Montserrat de la galería.

## Estructura
- `/index.html`: página principal.
- `/styles.css` y `/site.js`: estilos y comportamiento.
- `/FrancoFlores/SesionLiz/`: galería de cliente.

La home se mantiene intencionalmente sencilla: presentación, enlace a la galería y contacto.

## Contacto
Configura `WHATSAPP_NUMBER` en `site.js` con tu número en formato internacional, solo dígitos.

## Publicación
Sube todo a la raíz del repositorio y activa GitHub Pages desde **Settings → Pages → Deploy from a branch → main → /(root)**.
